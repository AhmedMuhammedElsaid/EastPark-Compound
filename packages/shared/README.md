# @eastpark/shared

Framework-agnostic EastPark domain logic shared by the web and mobile apps.

Allowed here:

- TypeScript domain and API contracts
- Zod schemas with translation-key messages
- Pure business rules
- Design tokens and translation data

Not allowed here:

- React, React Native, Next.js, Expo, or UI components
- Browser or device storage
- Axios/fetch clients or navigation
- Environment-specific configuration

The package is path-only and private to the local pnpm workspace.
