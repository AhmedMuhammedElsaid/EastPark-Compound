# EastPark — Impeccable Design Context

## Design Context

### Users

**Age range:** 20–60. Wide demographic — design must feel modern without alienating older users. Legibility and clarity are non-negotiable. Minimum 14sp body text, 16sp for primary content, 48dp preferred touch targets.

**Primary user:** Residents of a gated residential compound in the MENA region. They interact with EastPark daily — ordering from compound shops, reading community announcements, voting in governance polls, and submitting service complaints. They open the app in-context: at home, on their phone, often in Arabic, frequently in low-attention moments.

**Secondary roles:** Guests (read-only browsers), Merchants (shop owners managing incoming orders), Compound Admins (posting announcements, managing elections and feedback).

**Job to be done:** Replace fragmented WhatsApp groups, paper notices, and in-person requests with a single trusted platform that handles commerce, governance, and compound management in one place.

**Emotional goal:** The interface should feel like the compound itself — premium, orderly, and trustworthy. Residents should feel *at home* the moment they open the app.

**Language context:** Arabic is the primary language, RTL is the primary layout direction. English (LTR) is a secondary language switchable in settings. Every design decision must hold up in both directions.

### Brand Personality

**Three words:** Prestige. Civic. Warm.

**Voice:** Calm authority. The app speaks like a well-managed property — clear, unhurried, and competent. Never chatty, never playful, never alarming without reason.

**Emotional register:**
- Commerce features → confidence, ease
- Community features → belonging, connection
- Governance features → trust, transparency
- Feedback/complaints → acknowledgment, resolution

**Reference apps (benchmark, not imitate):**
- **MyGate** — foundational structure: quick actions, status timelines, role-based layouts, civic UX patterns
- **Talabat** — commerce excellence: carousels, category chips, skeleton loading, cart mechanics
- **Facebook** — engagement depth: card feeds, reactions, comments, infinite scroll
- **YouTube** — premium transitions: smooth navigation, sticky chip bars, auto-dismiss overlays

### Aesthetic Direction

**Visual tone:** Luxury residential, MENA prestige. The logo — white serif wordmark on deep black with a warm gold geometric diamond mark — defines the register. This is not a startup. This is not a utility app. This is a premium community platform.

**Theme:** Dark mode is the flagship design experience and the default on first launch. Light mode is available as a user-toggled preference. All design decisions must be dark-mode-first, with light mode as a considered variant — not an afterthought.

**Color rules:**
- Gold `#b8966a` is reserved for primary interaction and meaningful accents only — never decorative fill
- Never use pure `#000000` or `#ffffff` as surfaces
- Never use cold zinc/gray tones (`#f4f4f5`, `#71717a`) — always warm equivalents
- Semantic colors are muted and premium — no neon, no candy

**Typography:**

| Font | Use | Languages |
|---|---|---|
| Cairo | All functional UI — buttons, inputs, nav, lists, body, labels, all Arabic text at every scale | Arabic + English |
| Cormorant Garamond | Display / hero moments only — splash, onboarding hero, app name lockup | English only — never Arabic |

Cairo type scale:
- Display: Bold 700, 28sp — hero text, large numbers
- Title: SemiBold 600, 20sp — screen titles, section headers
- Body-lg: Medium 500, 16sp — shop names, primary content
- Body: Regular 400, 14sp — descriptions, list items
- Label: Medium 500, 13sp — chip labels, badge text, button text
- Caption: Regular 400, 12sp — timestamps, metadata, helper text

Typography rules:
- Cormorant Garamond is strictly decorative, English-only, display-only — never in data-heavy UI
- Prices, order numbers, OTP codes always render LTR (Unicode BiDi) regardless of app direction
- Minimum body line height 1.5× for readability and accessibility
- Gold text only at Bold weight minimum to meet contrast thresholds

**Spacing and layout:**

| Token | Value |
|---|---|
| radius-xs | 4dp |
| radius-sm | 8dp |
| radius-md | 12dp (standard card radius) |
| radius-lg | 16dp |
| radius-xl | 24dp |
| radius-full | 9999 (pill shape) |

- Touch targets: 44dp minimum, 48dp preferred on all interactive elements
- Cards: 12dp corner radius, warm gold-tinted shadow `rgba(184,150,106,0.10)`, never cold drop shadows
- Shadow deepens on pressed/active state

**Motion:** Rich and delightful — every screen should feel alive. This is the explicit design intent.
- Spring physics on all bottom sheets and card interactions
- Lottie animations on every key confirmation moment: order placed, vote submitted, complaint resolved, registration complete, payment success
- Parallax depth on the hero carousel
- Poll percentage bars animate from 0% to result on vote (600ms spring)
- Cart badge bounces on item add; tab icons scale on press
- Skeleton shimmer on all loading states — never a spinner on list screens
- Smooth shared-element transitions between screens where Reanimated supports it
- Haptic feedback paired with every visual interaction (success, warning, error)
- Respect system `prefers-reduced-motion` — fall back to opacity-only or instant

**Empty states:** Branded Lottie animations paired with a warm headline and supporting copy. Each major screen gets its own — never reuse a generic placeholder.

**Empty states:** Branded Lottie animations paired with a warm headline and supporting text. Each major screen gets its own empty state — never reuse a generic placeholder.

**Anti-references (what NOT to build):**
- No cold blue / zinc gray palette — Material Design defaults, generic SaaS aesthetic
- No rounded-everything, card-in-card-in-card nesting
- No gradient buttons or neon accent colors
- No startup-trendy design that ages in 18 months
- No hamburger menus or complex drawer navigation
- No FlatList — use @shopify/flash-list throughout

### Design Principles

1. **Prestige over perk.** Every decision should feel considered and intentional — not gratuitous or showy. The gold is used sparingly because it means something when it appears. Less is more.

2. **Warm, never cold.** All surfaces, shadows, and neutral tones carry warm undertones. Cold zinc and clinical white have no place in EastPark. The compound is a home, not a dashboard.

3. **Arabic-native, bilingual-ready.** Design RTL-first. Every layout, icon choice, and navigation pattern must work flawlessly in Arabic before English is considered. Typography, spacing, and tap targets are all calibrated for Arabic readability.

4. **Dark is the default, light is a choice.** Dark mode is the flagship experience. It ships first, it looks best, it reflects the brand identity. Light mode follows — it does not lead.

5. **Alive, not showy.** Motion is rich and expressive — spring physics, Lottie moments, micro-interactions on every screen. But every animation earns its place. If removing it makes the interaction feel worse, keep it. If it's decoration, cut it. Reduce gracefully for users who prefer less.

6. **Trust through consistency.** Civic features — polls, complaints, announcements — demand predictable, reliable UI. No surprises, no ambiguity, no UI that obscures status. Residents should always know exactly where they are and what happens next.

---

### Accessibility

**Standard:** WCAG AA
- Text contrast ≥ 4.5:1 (normal), ≥ 3:1 (large — 18sp+ or bold 14sp+)
- Touch targets: 44dp minimum, 48dp preferred
- `accessibilityLabel` and `accessibilityRole` on all interactive elements
- VoiceOver (iOS) and TalkBack (Android) support for all primary flows
- Gold `#b8966a` must NOT be used as body text on light backgrounds — use `gold-700` `#7a5e38` for text on light surfaces (passes AA)
- Gold on `#0d0c0b` dark background: passes AA (verified ~4.7:1)
- `prefers-reduced-motion`: Lottie and spring animations fall back to opacity transitions or instant state change

## Tech Stack Reference

- **Framework:** Expo 54 + React Native 0.81.5, New Architecture, Hermes
- **Language:** TypeScript (strict)
- **Styling:** NativeWind v4 (Tailwind for React Native)
- **Components:** Gluestack UI v2 (NativeWind-compatible)
- **Navigation:** Expo Router + React Navigation
- **State:** Redux Toolkit + TanStack React Query
- **Animation:** react-native-reanimated v4, Lottie
- **Icons:** Phosphor Icons (RTL-friendly)
- **Lists:** @shopify/flash-list (never FlatList)
- **Sheets:** @gorhom/bottom-sheet
- **Fonts:** @expo-google-fonts/cairo, @expo-google-fonts/cormorant-garamond
